---
title: Choices
description: Let players choose between story branches.
---

**Need-To-Know Information before you read**: In order for any action to do something that requires interaction, put it in an event trigger.

How to Use Choices:

- Add a new action and select **Choices**, now once you’ve opened up the new choices action you made, click the **+ Add Choice** button; Choice Text represents what the prompt says when the player is shown the choices.

  ```
    ex: Jump in the well?
        Yes
        No
  ```

  In order for your choice to actually do something, you need to add some actions to it, which can be anything.

- If you don’t like the way the choices box looks like, you can go to the Project Tab, and then go to UI > Choices Layout, and either make a new layout, or edit the default one.
